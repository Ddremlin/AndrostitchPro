# AndrostitchPro — редактор схем вышивки крестом для Android

Собственное приложение на Kotlin + Jetpack Compose (не порт и не копия чужого кода).

## Что умеет (версия 0.4)
- **Редактор сетки:** крест, полукрест «/» и «\», ¼ и ¾ креста (угол выбирается по месту касания в клетке), бэкстич, французские узелки, бисер, ластик, заливка, пипетка
- **Выделение:** копирование, вырезание, удаление, перемещение и вставка фрагментов (в том числе в другую схему)
- **Режим «вышиваю»:** отметка вышитых клеток, процент готовности всего и по каждому цвету, подсветка выбранного цвета
- **Палитры ниток:** встроенная DMC и любые свои из CSV (код;название;R;G;B), перевод схемы на другую фирму, похожие нитки других фирм для каждого цвета
- **Масштаб и прокрутка:** двумя пальцами в любом инструменте, одним пальцем в режиме «Рука»
- **Отмена и повтор:** до 50 шагов
- **Палитра DMC:** 429 цветов, поиск по номеру и названию, свой символ у каждого цвета; долгое нажатие на цвет позволяет заменить нитку или удалить цвет
- **Фото → схема:** обрезка (свободная, 1:1, 3:4, 4:3), учёт поворота снимка, ширина в крестиках, число цветов, сглаживание (дизеринг), белый фон можно не вышивать; подбор ниток DMC в пространстве CIE Lab
- **Виды:** цвет, символы или цвет с символами
- **Отражение, поворот, изменение размера холста**
- **Расчёты:** размер на Aida 11/14/16/18, расход ниток по цветам в мотках
- **Экспорт:** PDF для печати (обложка с легендой и листы схемы с нумерацией по 10 клеток), PNG, а также собственный файл .stp для обмена
- **Сохранение:** «Мои схемы» и автосохранение при сворачивании приложения

## Сборка
**Android Studio:** откройте папку проекта, дождитесь синхронизации Gradle и нажмите Run.

**GitHub Actions (без Android Studio):** залейте проект в репозиторий. Workflow `.github/workflows/build.yml`
соберёт APK. Готовый файл появится во вкладке Actions → последний запуск → Artifacts → `StitchPad-debug-apk`.

**Командная строка:** `./gradlew assembleDebug` (нужны JDK 17 и Android SDK 35).

## Структура
- `core/` — чистый Kotlin без Android: модель схемы, преобразования, цвета DMC, квантование фото, формат файла, расход ниток
- `ui/` — Compose: холст, экран редактора, диалоги, ViewModel, экспорт PDF и PNG
- `assets/dmc.csv` — таблица цветов DMC (код; название; R; G; B), значения RGB приблизительные

## Идеи для следующих версий
Библиотека мотивов, две нитки разных цветов в одной клетке (blended), поворот и отражение выделенного фрагмента.
